## Privacy Policy: Measure Inspector+

**Last updated: 2026-05-13**

## Overview

Measure Inspector+ (Measure Inspector Plus) is a browser extension that provides on-page measurement tools for web designers and developers. This privacy policy explains how the extension handles data.

## Data Collection

Measure Inspector+ **does not collect any data**. Specifically:

- No personal information is collected
- No page content, form data, or user input is read or stored
- No browsing history or activity is tracked
- No analytics or telemetry is sent anywhere

## Data Storage

The extension stores only one preference locally on your device:

- **Panel width setting** — saved via `chrome.storage.local` to remember your UI layout preference

This data never leaves your device and is automatically deleted when the extension is uninstalled.

## Network Activity

Measure Inspector+ makes **no network requests**. There are no external servers, APIs, or third-party services involved.

## Permissions

The extension requires the following permissions:

- **Access to all websites** (`<all_urls>`): Required to display the measurement overlay on any page the user is visiting. No page content is read or transmitted.
- **scripting**: Required to inject the measurement UI when the user activates the tool by clicking the toolbar icon.
- **storage**: Required to save the panel width preference locally.

## Contact

If you have any questions about this privacy policy, please open an issue on the project repository.

## 隱私權政策：Measure Inspector+

**最後更新：2026-05-13**

## 概述

Measure Inspector+（Measure Inspector Plus）是一款瀏覽器擴充功能，為網頁設計師與開發者提供頁面上的測量工具。本隱私權政策說明此擴充功能如何處理資料。

## 資料蒐集

Measure Inspector+ **不會蒐集任何資料**。具體而言：

- 不會蒐集個人資料
- 不會讀取或儲存頁面內容、表單資料或使用者輸入
- 不會追蹤瀏覽紀錄或使用活動
- 不會傳送任何分析資料或遙測資料

## 資料儲存

此擴充功能只會在您的裝置本機儲存一項偏好設定：

- **面板寬度設定**：透過 `chrome.storage.local` 儲存，用於記住您的介面配置偏好

此資料不會離開您的裝置，並會在解除安裝擴充功能時自動刪除。

## 網路活動

Measure Inspector+ **不會發出任何網路請求**。此擴充功能不涉及外部伺服器、API 或第三方服務。

## 權限

此擴充功能需要以下權限：

- **存取所有網站**（`<all_urls>`）：用於在使用者瀏覽的任何頁面上顯示測量覆蓋層。不會讀取或傳送頁面內容。
- **scripting**：用於在使用者點擊工具列圖示啟用工具時，注入測量介面。
- **storage**：用於在本機儲存面板寬度偏好設定。

## 聯絡方式

若您對本隱私權政策有任何問題，請於專案儲存庫提出 issue。

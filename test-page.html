MeasureTool Test Page

Enable the extension and hover over any element to start measuring

How to use:
1. Click the 📐 icon in the browser toolbar to open the tool
2. Hover over elements to view size and CSS properties
3. Click to pin an element, then hover others to measure distance
4. Shift+Click to select multiple elements
5. Press H / V to add horizontal / vertical guides at cursor position
6. Press Q to clear all guides, Esc to deselect
7. Press ↑↓ to navigate parent / child in the DOM tree
